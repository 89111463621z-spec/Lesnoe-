# Лесное ожерелье — сайт посёлка

Одностраничный сайт коттеджного посёлка «Лесное ожерелье»: описание, преимущества, интерактивный план участков, карта и заявка в Битрикс24.

## Как поменять цену или статус участка

Всё в одном файле: `assets/js/prices.js`.

```js
16: { area: 850, price: 1530000, status: "free" },
```

- **Продали участок** — удалите его строку. Участок станет серым («продан»).
- **Бронь** — поставьте `status: "reserved"`. Участок станет жёлтым.
- **Новая цена** — число без пробелов: `price: 1450000`.
- `area` — площадь в м², в сотки сайт переводит сам.

Счётчик «осталось участков» и цена «от …» на первом экране пересчитываются автоматически.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | страница |
| `politika.html` | политика обработки персональных данных |
| `assets/css/style.css` | оформление |
| `assets/js/prices.js` | цены и статусы участков |
| `assets/js/plan.js` | контуры участков из схемы «Нумерация ЗУ с промерами» (не редактировать) |
| `assets/js/main.js` | логика плана и анимаций |
| `assets/img/` | обработанные фото (WebP) |
| `integrations/bitrix24-form.html` | код CRM-формы Битрикс24 (форма №23) |

## Публикация

Сайт статический и работает на GitHub Pages: Settings → Pages → Deploy from a branch → выбрать ветку и папку `/ (root)`.
